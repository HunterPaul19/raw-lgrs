# Machine Learning Day 1

## What it is
Today I built a linear regression model using MSE (Mean Squared Error) as my loss function and a single variable model using mx + b.

I generate a sample synthetic data set with noise around a set y line and train the model on this data to predict accurate outputs on new data inputs

I visualize and animate this training using matplotlib, I also visualize how the margin for error goes down with more epochs for training.

Overall this was a super simple and fun project which helped get me caught up on linear algebra fundamentals and understand the building blocks for how models get trained to predict outputs based off of inputs
